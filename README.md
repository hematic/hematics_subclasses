# Hematic's Subclasses

A collection of homebrew subclasses for D&D 5e, packaged as a Foundry VTT module.

## Installation

In Foundry, go to **Add-on Modules → Install Module** and paste this manifest URL:

```
https://raw.githubusercontent.com/hematic/hematics_subclasses/main/module.json
```

Then enable the module in your world. The subclasses live in the **Subclasses**
compendium under the *Hematic's Magic Modules* folder.

## Compatibility

- Foundry VTT v13+ (verified on v14)
- System: dnd5e
